# M18 Rewards Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build deterministic Scrap, card/relic offers, and idempotent reward choice.

**Architecture:** A pure `src/engine/rewards.ts` accepts an explicit catalog rather than reading files, stores versioned `RewardState` in `AuthoritativeState`, and uses gameplay RNG. M19 will invoke its public commands after combat; it owns no map or run routing.

**Tech Stack:** TypeScript, Vitest, React, Vite, existing gameplay RNG.

**Spec:** `docs/superpowers/specs/2026-09-11-m18-rewards-design.md`

## Global Constraints

- No dependency, schema, map, save, shop, or profile changes.
- Use content metadata and never branch on a card or relic ID.
- Keep only one pending reward and make completed transaction IDs idempotent.
- Use the existing Blank Badge option-count channel.

### Task 1: Reward state and public contracts

**Files:** Create `src/engine/rewards.ts`; modify `src/engine/state.ts` and `src/engine/index.ts`; test `tests/unit/rewards.test.ts`.

**Interfaces:** `createRewardState()`, `RewardState`, `RewardCatalog`, `RewardEncounterKind`, and `PendingReward`; `AuthoritativeState.rewards` is initialized with `{ rewardVersion: 1, scrap: 0, pending: null, completedTransactionIds: [] }`.

### Task 2: Deterministic offer generation

**Files:** Modify `src/engine/rewards.ts`; test `tests/unit/rewards.test.ts`.

**Interfaces:** `createEncounterReward(state, catalog, input)` accepts transaction ID, encounter kind, selected roles, unlocked IDs, and owned relic IDs. It returns an updated state with a pending offer.

- [ ] Write failing fixed-seed tests for equal offers, Source/Shaper guarantees, no duplicate IDs, locked/unselected exclusion, and owned-relic exclusion.
- [ ] Add ordinary rarity weights 65/30/5, elite weights 20/60/20, and normalize each role's remaining rarity weights.
- [ ] Obtain card slot count through `cardRewardOptionCount(state)`; extra slots use Source/Shaper/Crew weights 40/40/20.
- [ ] Grant 15 Scrap for ordinary, 35 for elite, and 50 for Act 1 boss; elite includes two relic options and boss three.
- [ ] Select then remove each definition from the eligible candidate list, rather than retrying, to prevent duplicates.
- [ ] Run `npx vitest run tests/unit/rewards.test.ts` and `npm run test:replay`.
- [ ] Commit with `feat: generate deterministic M18 reward offers`.

### Task 3: Claim/skip transaction semantics

- [ ] Run focused rewards, `npm run test:engine`, and `npm run test:properties`.
